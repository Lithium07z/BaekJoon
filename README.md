# BaekJoon | Algorithm Problem Solving

백준 온라인 저지(BOJ)와 프로그래머스에서 해결한 **알고리즘 문제 풀이를 기록하는 저장소**입니다.

문제 풀이 코드를 난이도별로 정리하고 있으며, 제출한 코드는 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)를 통해 자동으로 저장됩니다.

## Platforms

* **Baekjoon Online Judge**
  https://www.acmicpc.net/

* **Programmers**
  https://school.programmers.co.kr/learn/challenges

## Languages

이 저장소에는 다음 언어로 작성한 풀이가 포함되어 있습니다.

* Java
* C++
* Rust

문제에 따라 동일한 문제를 여러 언어로 해결한 코드가 함께 저장되어 있을 수 있습니다.

## Repository Structure

```text
BaekJoon/
├── 백준/
│   ├── Bronze/
│   ├── Silver/
│   ├── Gold/
│   ├── Platinum/
│   └── Unrated/
│
├── 프로그래머스/
│   ├── 1/
│   ├── 2/
│   ├── 3/
│   ├── 4/
│   ├── lv0/
│   ├── lv1/
│   ├── lv2/
│   └── lv3/
│
└── README.md
```

백준 문제는 **티어별**, 프로그래머스 문제는 **레벨별** 디렉터리에 정리되어 있습니다.

각 문제 디렉터리는 기본적으로 다음과 같은 형태로 구성됩니다.

```text
문제번호. 문제이름/
├── 문제이름.java   # 또는 .cc, .rs
└── README.md
```

## Problem Information

각 문제 폴더의 `README.md`에는 BaekjoonHub를 통해 문제와 관련된 정보가 함께 기록됩니다.

* 문제 번호 및 문제명
* 원본 문제 링크
* 실행 시간 및 메모리 사용량
* 알고리즘 분류
* 제출 일자
* 문제 설명
* 입력 및 출력 조건

따라서 소스 코드뿐 아니라 해당 문제의 기본 정보와 제출 결과도 함께 확인할 수 있습니다.

## Topics

기초적인 구현 문제부터 자료구조, 정렬, 그래프 탐색, 최단 경로, 동적 계획법, 그리디, 기하 등 다양한 유형의 알고리즘 문제 풀이를 기록하고 있습니다.

새로운 문제를 해결하면서 지속적으로 풀이를 추가합니다.

## Auto Upload

문제 풀이 제출 후 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)를 이용해 GitHub에 자동으로 업로드합니다.

이를 통해 제출 당시의 코드와 문제 정보를 그대로 보관하고 알고리즘 학습 기록을 관리합니다.

## Note

이 저장소는 개인적인 **알고리즘 학습 및 문제 풀이 기록**을 목적으로 합니다.

각 코드는 문제를 해결했을 당시의 제출 코드를 기준으로 보관하고 있으므로, 항상 가장 짧거나 최적화된 풀이를 의미하지는 않습니다.
